# AMCL 検証ゲート (動きの合意による AMCL 検証ゲートと、地図照合による判定)

推定器 (例: AMCL) の姿勢を融合 (例: EKF) に入れる前に確かめる AMCL 検証ゲート。疑わしい動きを見つけたら AMCL 検証ゲートを閉じ、地図照合で正しい姿勢を決めてから開ける。

中核は `core/motion_gate.py` (ROS に依存しない)。自己位置監視ノードの中で、自己位置監視の部品として動く (自己位置監視の設定の `gate` 節、ノードのパラメータ `use_gate`)。自己位置監視との分担は [design.md](./design.md#AMCL 検証ゲートを入れたとき)。姿勢補正と推定器の AMCL 検証ゲートの持ち主は自己位置監視ノード 1 つになる。

最終形は [architecture_target.md](./architecture_target.md)。

## 役割の分担

| 役 | 担うもの | 決めないこと |
| :--- | :--- | :--- |
| 気づく | 遮断条件 (判定。動きの合意、GNSS との食い違いなど) | どの姿勢が正しいか |
| 判定する | 地図照合 (候補のうち、どれが地図に合うか) | — |
| 対処する | AMCL 検証ゲートの開閉 (ゲートの調停ノード経由)、姿勢補正、停止要求 | — |

遮断条件は「何か変だ」を出すだけで、AMCL 検証ゲートを開けるのは照合が決めたときだけ。そのため、遮断条件が誤って閉じても、照合 1 回で元に戻る。遮断条件を足すのは安く、検出器 (センサやアルゴリズム) を足しても中核は変わらない。

## 流れ

```
情報源 (推定器・GNSS・融合の結果・動き・地図とスキャン)
  │
  ├─► 遮断条件 ──異常──► AMCL 検証ゲートを閉じる ──► 照合で決める ──► 補正する / そのまま採る ──► AMCL 検証ゲートを開ける
  │                                              │ 決まらない
  │                                              └─► 待ってやり直す (閉じている時間・距離の上限で一時停止を求める)
  │
  └─► 一定の距離ごとの確かめ (AMCL 検証ゲートが開いている間。推定器の周りだけを狭く照合し、合えば「検証済み姿勢」を更新)
```

## 状態

| 状態 | 意味 | AMCL 検証ゲート | `LocalizationStatus` の state |
| :--- | :--- | :--- | :--- |
| 未初期化 | 起動の直後、地図の切り替えの後。未初期化 | 開ける (推定器の収束を融合に通す)。照合で確かめるまで、遮断条件は使わない | `NORMAL` (猶予の間) |
| 開 | 検証済み姿勢があり、遮断条件がない | 開ける | `NORMAL` |
| 閉 | 遮断条件が異常を出した。照合の決着を待つ | 閉じる | `ISOLATED` (決まらずに止めている間は `DEGRADED`) |
| 止めて戻す | 大きい補正に決まり、止まってから補正する | 閉じる | `RECOVERING` |

## 遮断条件

自己位置監視と同じ判定の部品 (`Detector`、[plugins.md](./plugins.md#判定-detector)) を使い、設定の `detectors` に並べる。どれか 1 つが異常なら AMCL 検証ゲートを閉じる (自己位置監視の総合のような累積はしない。判定は照合に任せる)。

| 部品 | 気づくもの | 気づけないもの |
| :--- | :--- | :--- |
| 動きの合意 | 推定器の動きが、動きの情報源 (オドメトリ) と合わない (飛び)。1 回ごとの差と、直近の一定時間の中で最も古く受け入れた姿勢を今に進めたものとの差の両方で比べる (少しずつの戻りを見逃さないため) | ゆっくりしたずれ (オドメトリとの食い違いが小さいまま進む) |
| GNSS との食い違い | 推定器の位置が、健全な GNSS から一定以上離れたまま続く (ゆっくりしたずれ) | GNSS が弱い区間のずれ |

動きの合意は、推定器の正しい直り (誤りから正しい姿勢へ動くこと) も飛びと同じに見る。そのため、閉じたら必ず照合で決め、正しい直りなら推定器をそのまま採る。

## 照合で決める

候補を地図と照合し、地図に最もよく合う候補に決める。照合の部品は `core/matcher/correlative.py`。

| 候補 | 中身 | 探す範囲 |
| :--- | :--- | :--- |
| 推測航法姿勢 | 最後に検証済み姿勢を、動きの情報源で今に進めたもの。AMCL 検証ゲートが閉じる前に誤った推定器を取り込んだ融合の結果に引かれない | 確かめてから走った道のりで広げる (上限あり) |
| 推定器 | 推定器の今の姿勢 (飛んだ後の姿勢を含む) | 狭い |
| 融合の結果 | 融合の結果 (EKF) の今の姿勢 | 狭い |
| GNSS | GNSS の位置。向きは推測航法姿勢から借りる | 申告の精度の倍で広げる (上限あり) |

- 範囲が狭い範囲を超える候補は、粗い格子で探して絞り込んでから細かく合わせる。
- 照合した後の姿勢どうしが近い候補を、同じ仮説にまとめる。向きが一定以上違えば、位置が近くても別の仮説にする。
- 最良の仮説と、離れた次点の一致率の差が足りなければ、決めずに待つ。
- 最良の仮説に推定器が入っていて、推定器の一致率が最良と見分けられないときは、照合の姿勢ではなく推定器をそのまま採る (一致率の山は近い所でほぼ平らで、照合の小さな向きの誤差で補正すると、走るほど位置の誤差に広がる)。
- 未初期化の間は、推定器が出してから、推定器・融合の結果・GNSS を候補に確かめる。推定器と同じ仮説に決まれば補正しない (収束の途中を邪魔しない)。GNSS を入れるのは、推定器と融合の結果がともにずれた起動 (動きながらの起動など) で、誤った姿勢を確かめてしまわないため。
- 初期全周探索 (設定の `initial_search`) があるときは、未初期化の処理を AMCL 検証ゲートの中の 1 か所にする ([未初期化の処理](#未初期化の処理-初期全周探索があるとき))。
- 決めた姿勢はスキャンの時刻のものなので、動きの情報源で今の時刻に進めてから出す。
- 照合は、周期の処理とは別のスレッドで回す。

## 未初期化の処理 (初期全周探索があるとき)

起動の直後と地図の切り替えの後の、未初期化間の決め方。推定器 (例: AMCL) を外から初期化する部品を別に置かず、AMCL 検証ゲートが決める。

- GNSS の申告の精度が続けて足りれば (`initial_gnss_max_std_m`・`initial_gnss_consecutive`)、GNSS の位置の周りで、直近のスキャン 1 回分を地図に向きの全周で照合する (`core/initial_search.py`)。はっきり合った姿勢を候補に足し、推定器・融合の結果・GNSS の候補と同じ照合の規則で比べる。推定器がまだ出していなくても、初期全周探索の候補だけで決められる。精度が足りた時点で、やり直しの間隔を待たずに照合する (起動の直後に、初期全周探索なしの照合が決まらなかったとき)。
- 推定器と同じ仮説に決まれば、補正せずに開ける。
- 別の仮説に補正するのは、初期全周探索の姿勢と同じ仮説に決まったときだけ。狭い候補だけで決まった別の仮説 (一致率が下限をわずかに超えるだけの GNSS の候補など) には補正しない。走行に使う姿勢がまだ定まっていないので、止まるのを待たずにその場で補正する。
- 初期全周探索が合わず (似た一致が並ぶ、点が足りないなど)、まだ一度も確かめていなければ、GNSS の位置を広い共分散で 1 回だけ補正する (推定器に広く探させる)。確かめていないので、未初期化のまま照合を続ける。
- 手動の初期姿勢を受けたら、それを優先する ([手動の初期姿勢](#手動の初期姿勢))。

## 戻し方

| 補正の大きさ | 戻し方 |
| :--- | :--- |
| 小さい | その場で補正して、AMCL 検証ゲートを開ける |
| 大きい | 一時停止を求め、止まったのを確かめてから姿勢補正、一時停止を解いて AMCL 検証ゲートを開ける。止める時間には上限があり、超えたら補正して解く |
| 推定器をそのまま採る | 補正せずに AMCL 検証ゲートを開ける |

姿勢補正は、推定器 (`/initialpose`) と融合 (`/set_pose`) の両方に送る (送り先は自己位置監視と同じ `resetters`、[plugins.md](./plugins.md#再初期化の送り先-poseresetter))。補正した後の一定の距離は、収束の途中なので動きの合意を使わない。

## 検証要求

走行側 (例: 計画用地図の障害物からの脱出の前) が、照合を 1 回求める (自己位置監視のノードの `~/request_verify`)。受け付けた要求に番号を振り、決着したら番号と結果を状態に出す (イベント `localization.verify_result`)。

| 照合の結果 | AMCL 検証ゲート | 結果 |
| :--- | :--- | :--- |
| 推定器をそのまま採れる | 検証済み姿勢を更新する | `confirmed` |
| 別の姿勢に決まった (近くても推定器をそのまま採れないときを含む) | 閉じて補正する (戻し方は補正の大きさで分ける) | `relocated` |
| 決まらない | 自己位置監視が閉じさせたときと同じく、閉じて止めて照合する | `undecided` |

- 候補は閉じたときと同じ。AMCL 検証ゲートが開いていないとき (未初期化、閉じて照合・停止の最中) と、照合の依頼を作れない (地図・スキャンがない) ときは、待たせずに `undecided` を返す。
- 要求の間隔に下限を置く (`verify_min_interval_sec`)。待っている要求があれば受け付けない。

## 判定だけのとき

設定の `observe_only` (ノードの `gate_observe_only`) では、遮断条件の判定と照合は同じに行い、AMCL 検証ゲートの中では補正したものとして続ける (決めた姿勢を検証済み姿勢にする)。外へは何もしない: AMCL 検証ゲートは開けたまま、姿勢補正を出さず (`localization.pose_reset` に `applied=false`)、止める要求も出さない。大きい補正でも止まるのを待たずに決める。自己位置監視も通知だけになる。実機で、AMCL 検証ゲートが誤って閉じる率と、照合が決めた姿勢を測るのに使う。

## 決まらないときの上限

AMCL 検証ゲートを閉じている間、融合は推定器なしで (GNSS とオドメトリで) 進む。閉じている時間か走った距離が上限を超えたら、一時停止を求め、止まったまま照合をやり直す。照合で決まったら解く。
止まったままでは観測が増えないので、一定の時間で決まらなければ解いて少し走らせ、また止まって照合する (止まったままにしない)。

拡大探索: 決まらずに止めた回数が `wide_search_after_holds` に達した後の停止の間は、推測航法姿勢 (なければ融合の結果) の周りを、初期全周探索 (`initial_search`) で向きの全周まで探し、はっきり合った姿勢を候補に足す (イベント `localization.wide_search`)。合えばほかの候補と同じ規則で比べる。

スキャン途絶: 最新のスキャンが `scan_buffer` の `max_scan_age_sec` より古い間 (LiDAR が止まったなど) は、照合も、照合を待つ停止もしない (イベント `localization.gate_scan_stale`)。溜めたスキャンをオドメトリで進めて照合すると、誤った姿勢へ補正するため。溜めたスキャンと、待っている照合・姿勢補正は捨て、スキャンが戻ったら溜め直してから照合する (`localization.gate_scan_fresh`)。

自己位置監視の部品として使うとき、自己位置監視が推定器の異常を確かめて閉じさせたら (`force_close`)、最初から上限を超えたものとして扱い、すぐ止めて照合する (自己位置監視は遮断条件より遅く気づくので、融合の結果も推定器に引かれているおそれがある)。自己位置監視が足した候補 (候補を作るものの候補) も照合する。自己位置監視が GNSS を疑っている間は、GNSS を使う遮断条件と GNSS の候補を使わない。GNSS の申告の精度が急に良くなったとき (直近の窓の最も悪い値から一定の倍率以上。`gnss_probation_*`) も、再採用待機の間は同じく使わない (屋根を抜けた直後など、位置はずれたまま申告だけが良くなるため。イベント `localization.gnss_probation`)。自己位置監視は、除外した GNSS を、除外を解いた後も、`gnss_hold_after_distrust` なら AMCL 検証ゲートが検証済み姿勢 (推定器を採ったもの) と GNSS の位置が申告の精度の範囲で合うまで疑義として扱い続け、AMCL 検証ゲートと復旧の候補に使わせない (疑う相手が推定器に移るだけで除外が解けることがあり、GNSS が正しいとは確かめていないため。合ったらイベント `localization.gnss_released`)。

## 手動の初期姿勢

- 専用のトピック (`manual_pose_topic`) で受けた姿勢は、人が与えたものとして扱う。人が与える姿勢のおおよその誤差を覆う範囲 (`gate` の `manual_xy_m`・`manual_yaw_rad`) で照合し、はっきり違えば合った姿勢へ直してから姿勢補正、その姿勢を検証済み姿勢にする (手動の姿勢補正で AMCL 検証ゲートを閉じない)。起動からの距離に依らず受ける。
- 専用のトピックを通らない `/initialpose` (別の道具や故障の注入) は、推定器の振る舞いとして遮断条件の判定を受ける。地図に合えば推定器の候補として採られ、合わなければ退けられる。

## 入出力

自己位置監視ノードの入出力 ([supervisor_node.md](./supervisor_node.md)) のうち、AMCL 検証ゲートが使うもの。

| 種類 | 名前 | 内容 |
| :--- | :--- | :--- |
| 購読 | 自己位置監視の設定の `sources` | 推定器・GNSS・融合の結果の姿勢、動き、地図とスキャン (自己位置監視と同じ入力のアダプタ、[plugins.md](./plugins.md#入力のアダプタ-sourceadapter)) |
| 購読 | `gate.manual_pose_topic` | 手動の初期姿勢 (`PoseWithCovarianceStamped`) |
| クライアント | 対処の `gate` | ゲートの調停ノードの、自己位置監視の窓口 (`SetBool`、[gate_arbiter.md](./gate_arbiter.md)) |
| 配信 | 役 (`role: estimator\|fused`) つきの `resetters` の送り先 | 姿勢補正 |
| 配信 | 対処 | 停止要求 (自己位置監視の `hold_requested` と AMCL 検証ゲートの止める要求の、どちらか) |
| 配信 | `/localization/status` | 状態。自己位置監視の状態と AMCL 検証ゲートの状態の重い方 |

## 設定

自己位置監視の設定の `gate` 節 ([parameters.md](./parameters.md#gate))。値は各ロボットの設定ファイルが正。

## 診断とイベント

- 診断: 状態 (自己位置監視と同じ形)、遮断条件ごとの結果、直近のイベント。
- イベント ([doc/monitoring.md](../../doc/monitoring.md) の書式):
  - `localization.gate_closed`: 閉じた理由の部品と、その値。
  - `localization.map_match`: 照合の結果 (依頼のわけ、決めた候補、決まらなかったわけ、入力のまま採れる候補、候補ごとの一致率、次点との差、直近の照合の所要時間)。決まらなかったときも出す。
  - `localization.gate_opened`: 開けたときの決め方 (起動の直後の確かめ / 推定器を採った / 補正した / 手動)。
  - `localization.gate_closed`: 自己位置監視が閉じさせたときは、理由が `supervisor`。
  - `localization.gate_map_changed`: 地図が替わったので、確かめる前に戻した。
  - `localization.pose_reset`: 姿勢補正の大きさと戻し方 (その場 / 止めて / 未初期化の間の決着 `startup` / GNSS の位置を広い共分散で出した `fallback`)。
  - `localization.initial_search`: 初期全周探索の結果 (合った / 決まらなかったわけ、一致率、次点との差、見つけた姿勢、GNSS の位置)。
  - `localization.hold`: 停止要求の始まりと終わり、理由 (大きい補正 / 決まらない)。
  - `localization.pose_confirmed`: 一定の距離ごとの確かめの結果。
  - `localization.manual_pose`: 手動の初期姿勢を受けたことと、照合で直したか。
  - `localization.wide_search`: 拡大探索の結果 (合った / 決まらなかったわけ、一致率、次点との差、見つけた姿勢、探した中心)。
  - `localization.verify_requested`・`localization.verify_result`: 走行側の検証要求の受け付けと結果 (確かめた / 補正した / 決まらない)。
  - `localization.gnss_probation`: GNSS の再採用待機の始まり (申告の精度と、窓の中の最も悪い値)。
  - `localization.gate_scan_stale`・`localization.gate_scan_fresh`: スキャンが途絶えたので照合をやめた・戻った。

## 評価

- 単体: 中核を ROS なしで、人工の姿勢・動き・地図で確かめる (照合の規則、正しい直りを締め出さない、上限、手動の姿勢)。
- 再生: 記録した rosbag を、本物の推定器と融合で再生し、故障を `/initialpose` から本物の推定器に入れる ([tools の localization_evaluation.md](../../tools/doc/localization_evaluation.md))。
- 走りへの影響 (戻し方): シミュレータのシナリオ。rosbag の再生では軌跡が決まっているので見られない。
